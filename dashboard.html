ℹ️ Comment utiliser le dashboard

1. Sélectionne ton serveur dans la liste à gauche
2. Navigue dans les sections pour configurer le bot
3. Modifie les paramètres et clique sur Sauvegarder
4. Les changements s'appliquent instantanément sur le bot

💡 Le bot lit la configuration directement depuis la base de données — pas besoin de redémarrage.
